# 系统字体大小工具页设计

本文记录将“字体缩放器”类能力加入 DPIS 工具页时的产品语义、界面结构和边界行为。该功能的本质是写入 Android 系统设置 `Settings.System.font_scale`，属于系统全局字体大小工具，不属于 DPIS 的按应用字体 Hook 链路。

## 产品语义

功能名称使用“系统字体大小”。

它表达的用户规则是：

- 修改 Android 全局字体缩放值。
- 影响跟随系统字体大小的应用。
- 不保证覆盖拥有独立字体设置、自绘文本或框架内字体缩放逻辑的应用。
- 不使用 Root、Xposed、LSPosed 或按应用 Hook。
- 需要用户授予“修改系统设置”权限。

避免使用“字体 Hook”“应用字体缩放”“强制字体缩放”这类名称，以免和 DPIS 已有的按应用字体链路混淆。“无需 Root”可以作为说明文案出现，但不作为主标题。

## 工具卡入口

工具页以工具卡片作为入口。第一版只需要一张“系统字体大小”卡片。

工具页顶部使用和设置页一致的页面标题区：

- 标题：工具

卡片常态结构：

- 左侧主标题：系统字体大小
- 左侧副标题：精确调整全局字体大小
- 标题旁状态徽标：展示 `需授权`、`已修改`、`不可用`、`超出范围` 等状态。
- 右侧圆形操作按钮：仅图标，不放文字。

右侧圆形操作按钮参考快捷模板卡片里的 `quick_template_select_button`，使用 `bg_round_button_surface`、固定 icon button 尺寸和 `AppCompatImageButton`。不要参考 `global_prefill_edit_button` 的 chevron 导航按钮，因为那是进入编辑页的导航语义。按钮位于主副标题右侧、卡片最右边，并在垂直方向居中。

圆形操作按钮语义：

- 当存在待应用改动时，按钮为可点击的保存态。
- 当没有待应用改动、未授权、不可用或当前值超出可写范围时，按钮为 disabled。
- 点击按钮写入待应用字体大小。
- disabled 态需要明显降级图标 tint，避免与可点击态都使用 `?attr/colorOnSurfaceVariant` 而无法区分。

点击卡片主体展开或收起控制区。右侧圆形操作按钮只负责应用待写入值，不负责展开。

## 状态徽标

状态徽标用于说明工具当前是否可以操作，以及当前系统值是否处在 DPIS 支持范围内。徽标只显示一个主状态，但文档需要明确组合状态的定性，避免 `超出范围` 和 `已修改` 互相覆盖后语义不清。

建议状态：

- `需授权`：没有 `WRITE_SETTINGS` 权限。
- `已修改`：当前系统字体值在 50% 到 200% 范围内，但不是 100%。
- `不可用`：当前系统值无法读取或系统拒绝访问。
- `超出范围`：读取到的实际值超过 50% 到 200% 的工具支持范围。

状态分两层判断：

- 操作阻断状态：`不可用`、`需授权`。
- 数值状态：`超出范围`、`已修改`、默认值。

主徽标优先级：

1. `不可用`
2. `需授权`
3. `超出范围`
4. `已修改`

组合语义：

- `超出范围` 不归入 `已修改`。它只表示读到的系统值不在工具可操作域内，不表达这个值是否由 DPIS 或用户主动改出。
- `已修改` 只用于当前值可读、已授权或未授权但可展示当前值、且当前值在 50% 到 200% 内但不等于 100% 的情况。
- `需授权 + 已修改` 时，主徽标显示 `需授权`；当前值仍显示实际百分比，例如 `当前 115%`。
- `需授权 + 超出范围` 时，主徽标显示 `需授权`；当前值仍显示实际百分比，并可在数值区提示 `超出范围`。
- `不可用` 覆盖所有数值状态，因为当前值不可判断。

如果没有以上状态，可以不显示徽标，或显示普通的当前百分比。

第一版徽标不需要为每个状态引入一套专用颜色。优先使用一套通用 surface/secondary-container 视觉，或复用 `help_tutorial_*_badge` 的 `MaterialTextView` + shape background 形式；后续确认需要风险分级时再拆状态色。

## 展开卡片结构

展开后的卡片分为标题区和操作区。

标题区沿用工具卡入口，不在展开内容中重复一套标题。

操作区包含：

- 数值区：居中显示待应用百分比。
- 调整区：`-1%`、待应用百分比、`+1%` 同行排列，滑条在下一行。
- 预览区：展示目标字体大小的视觉效果，只放两行示例文字。
- 权限面板：未授权时替代完整操作区。

没有权限时，不展示完整操作区，避免未授权状态下卡片展开过大。卡片只显示一个轻量授权面板，整块面板可点击并打开系统授权页。授权面板中的“点击授予权限”是提示文本，不再作为独立按钮。

不可用状态也保留展开能力，但操作区全部 disabled，并显示不可用提示。它可以复用遮罩结构，但文案应区别于授权遮罩，例如“无法读取当前系统字体大小”。

## 权限流程

启动工具页、展开卡片、从系统设置页返回时，都重新读取：

```text
Settings.System.canWrite(context)
```

未授权时显示权限遮罩：

- 面板文案：点击授予权限
- 面板位置：卡片标题区下方
- 点击行为：整块面板打开系统授权页

授权入口：

```text
android.settings.action.MANAGE_WRITE_SETTINGS
package:<当前包名>
```

返回页面后重新读取授权状态和当前系统字体值。

实现接入建议：

- 新建 `ToolsWorkspaceBinder`，按 `SettingsWorkspaceBinder` 的模式接入 `bind`、`onStart`、`onResume`、`onStop` 和 `onActivityResult`。
- `ToolsWorkspaceBinder` 持有 `SystemFontScaleToolBinder`，由后者负责读取权限、读取系统值、写入系统值和刷新 UI。
- `MainActivity` 持有 `ToolsWorkspaceBinder` 并转发生命周期，和现有 settings workspace 保持同类结构。
- `WRITE_SETTINGS` 授权页返回后主要依靠 `onResume` 重读状态；如果实现使用 `startActivityForResult`，再分配独立 request code 并通过 `ToolsWorkspaceBinder.onActivityResult` 转发。
- 切换 workspace 后第一版不保持卡片展开状态；重新进入工具页时从收起状态开始，但重新读取权限和当前系统字体值。

## 数值模型

界面显示统一使用百分比，内部写入统一使用 `font_scale` 浮点值。

推荐常量：

```text
SYSTEM_FONT_SCALE_MIN_PERCENT = 50
SYSTEM_FONT_SCALE_MAX_PERCENT = 200
SYSTEM_FONT_SCALE_DEFAULT_PERCENT = 100
```

推荐状态命名：

```text
currentSystemFontScalePercent
pendingSystemFontScalePercent
```

含义：

- `currentSystemFontScalePercent`：从系统读取到的当前实际值。
- `pendingSystemFontScalePercent`：用户正在选择但尚未应用的目标值。

写入换算：

```text
font_scale = pendingSystemFontScalePercent / 100f
```

## 调整方式

第一版不采用拖动即写入。更清楚的交互语义是：

- 滑条拖动只更新待应用值和预览。
- 点击右侧圆形保存按钮后才写入系统设置。
- 写入成功后刷新当前实际值，并同步待应用值。

推荐范围：

- 最小值：50%
- 默认值：100%
- 最大值：200%

推荐粒度：

- 滑条步进：1%
- 精调按钮：`-1%`、`+1%`

调整区布局：

- `-1%` 按钮在左侧。
- 待应用百分比在中间。
- `+1%` 按钮在右侧。
- 滑条在下一行，使用设置页同款 Material Slider。
- 滑条值按 1% 离散步进吸附，但不显示中间密集刻度；视觉上只保留左右端点的范围边界。

边界要求：

- 待应用值限制在 50% 到 200%。
- 滑条天然不能产生 50% 以下或 200% 以上的待应用值。
- `-1%` 和 `+1%` 也必须操作待应用值，而不是直接操作当前系统值。
- `-1%` 按钮在待应用值为 50% 时禁用。
- `+1%` 按钮在待应用值为 200% 时禁用。
- 当前系统值超出范围时，当前值文本原样显示，滑条位置夹到最近可调范围；这个夹取值只是工具内的初始候选值。

## 预览设计

预览区用于表达“待应用值”的视觉效果，不承诺所有应用都会完全一致。

第一版预览不要做得过高，使用两行示例文字即可：

- 标题或强调文本
- 正文文本

预览字号根据 `pendingSystemFontScalePercent` 实时变化，不对预览字号单独封顶。200% 就应该按 200% 展示，否则预览会失去判断意义。

实现时避免把当前系统字体缩放和目标缩放叠加两次。建议按基准 sp 计算目标 px：

```text
previewTextSizePx = baseSp * density * pendingSystemFontScalePercent / 100f
```

其中 `density` 使用普通密度，而不是已经包含当前系统 font scale 的 `scaledDensity`。如果只能从 `TextView.setTextSize` 传 sp 值，则需要先抵消当前系统 font scale，确保预览表达的是目标百分比本身。

为了避免大字号预览挤压下方操作，第一版预览区只保留标题和正文两行样本文字，不在预览区内追加说明文字。页面高度由滚动容器承载，不通过压低预览字号来解决。

## 应用与恢复

应用动作由工具卡右侧圆形按钮承担。

应用规则：

- 只有已授权、当前值可读、待应用值在范围内、且待应用值不同于当前实际值时可点击。
- 点击后写入 `Settings.System.putFloat(contentResolver, "font_scale", pending / 100f)`。
- 写入成功后刷新当前值。
- 写入失败时保留待应用值，并用 Toast 提示。

恢复动作使用“恢复 100%”语义，但写入优先级由当前系统实际值决定。

恢复按钮优先恢复系统实际值：

- 当当前系统值可读、已授权、且当前系统值不是 100% 时，点击“恢复 100%”直接写入系统默认值，即使滑条存在未保存改动也不需要二次点击：

```text
Settings.System.putFloat(contentResolver, "font_scale", 1.0f)
```

- 当当前系统值已经是 100%，但 `pendingSystemFontScalePercent != 100` 时，点击“恢复 100%”只把待应用值和滑条位置移回 100%，同步更新预览，不写入 `Settings.System.font_scale`。

因此，如果系统实际值不是 100%，恢复按钮承担的是立即恢复系统默认值的职责；只有系统已经处于默认值时，它才承担撤回待应用选择的职责。它不等同于“撤回到打开前”，第一版不需要实现打开前快照的撤回语义。

恢复按钮在以下任一条件成立时可点击：

- 待应用值不是 100%。
- 当前系统值可读、已授权、且当前系统值不是 100%。

恢复按钮放在展开卡片底部，使用次要按钮样式，例如 `TextButton` 或 tonal button。不要放进卡片常态头部，避免和右侧圆形保存按钮争抢主操作语义。

恢复按钮不能使用固定 `layout_height` 裁切文字。它应使用 `wrap_content` 高度和最小触控高度，确保系统字体放大到 200% 时按钮文本仍完整显示。

## 边界行为

读不到当前系统值：

- 状态徽标显示 `不可用`。
- 当前值显示“无法读取当前值”。
- 禁用右侧圆形操作按钮。
- 禁用调整控件。

没有写权限：

- 状态徽标显示 `需授权`。
- 操作区显示权限遮罩。
- 右侧圆形操作按钮 disabled。

写入失败：

- 保留 `pendingSystemFontScalePercent`。
- Toast 提示“系统拒绝了字体应用”。
- 重新读取当前系统值，避免 UI 与系统状态脱节。

选择范围外数值：

- UI 不允许选择。
- 滑条与 `-1%`、`+1%` 按钮都必须受 50% 到 200% 限制。

当前系统值超出范围：

- 状态徽标显示 `超出范围`。
- 当前值文本原样显示，例如 `当前 220%`。
- 该状态定性为“系统当前值不在工具可操作域”，不定性为 `已修改`。
- 滑条位置夹到最近可调范围，只表示可调范围内的初始候选值，不自动视为用户已经选择。
- 右侧圆形操作按钮 disabled，直到用户主动调整出一个范围内待应用值。
- “恢复 100%”仍然可用，用于把系统值带回默认值。

## 与 DPIS 字体链路的关系

该工具不写入按应用配置，不改变应用列表里的目标配置，也不参与字体 Hook 链路选择。

两者的区别是：

- 系统字体大小：写 Android 全局 `font_scale`，影响跟随系统设置的应用。
- DPIS 按应用字体缩放：通过运行时路由改变特定应用读取到的字体缩放或文本尺寸。

工具页 UI 应让用户能看出这是一个全局系统工具，而不是某个应用的配置项。

需要额外说明的是：系统全局 `font_scale` 会成为部分运行时路由观察到的系统基线。例如 ActivityThread/Resources 类路由可能从当前 `Configuration.fontScale` 开始再应用 DPIS 的按应用目标值。因此工具页文案可以提示“DPIS 按应用字体缩放可能在系统字体大小基础上生效”。这不是本工具写入按应用配置，而是系统配置成为运行时输入。

## 资源与测试

资源要求：

- 工具页替换 `tools_workspace.xml` 的“Under construction”占位。
- UI 文案必须同时添加到默认 `values/strings.xml` 和 `values-zh-rCN/strings.xml`。
- 卡片尺寸、间距和圆形按钮尺寸优先复用 `template_workspace_*` dimen，只有无法表达工具语义时才新增 dimen。
- 状态、错误、授权、恢复、预览提示等文本都放入字符串资源。

测试建议：

- `SystemFontScaleToolStateTest`：覆盖状态计算、按钮启用禁用、50%/200% 边界、超出范围、未授权和不可用。
- `SystemFontScaleToolLayoutSmokeTest`：检查工具页布局包含卡片、授权遮罩、Material Slider、精调按钮、预览、恢复按钮和右侧圆形操作按钮；滑条保留 1% 步进但不显示中间密集刻度。
- `ToolsWorkspaceBinderSourceSmokeTest`：检查 `MainActivity` 创建并转发 `ToolsWorkspaceBinder`，以及 binder 接入生命周期和授权返回刷新。

## 第一版实现形态

第一版推荐实现为：

- 工具页第一张卡片“系统字体大小”。
- 工具页顶部展示和设置页一致的标题“工具”。
- 常态卡片展示主副标题、状态徽标和右侧圆形保存按钮，不在副标题下方显示当前值。
- 点击卡片展开控制区。
- 未授权时不展示完整操作区，只显示可整块点击的授权面板。
- 调整范围固定为 50% 到 200%，步进 1%。
- `-1%`、待应用百分比、`+1%` 同行排列，滑条在下一行。
- 滑条和精调按钮只更新待应用值。
- 点击右侧圆形保存按钮才写入系统设置。
- 预览区只放两行示例文字。
- 恢复 100% 作为次要操作；有未保存滑条改动时只把待应用值移回 100%，没有待应用偏移时才写入系统默认值。

这个形态保留样本 APK 的核心能力，同时明确它是全局系统工具，避免和 DPIS 现有按应用字体缩放能力产生语义重叠。
