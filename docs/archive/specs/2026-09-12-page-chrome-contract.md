# 页面顶栏与滚动合同

日期：2026-09-12  
状态：已落地（2026-09-13 归档）

本文只定「进页时顶上看见什么、手指动时谁动」。不规定具体类名。宿主分层参考 InstallerX-Revived：壳只做导航并下发 padding，页自己拥有顶栏和列表。

## 三条硬规则

1. **顶槽高度永远不变。** 顶槽是一条窄栏（返回、短标题、搜索、操作）。滚动时不长高、不缩短。列表的测量高度不跟随折叠进度变化。
2. **大标题是列表第一项，不是另一套滚动。** 有大标题的页：大字是 LazyColumn 的 item 0，跟卡片共用同一次滑动、同一套 fling。顶槽高度不变；短标题只随这项滚走的比例淡入。松手时若大标题只露一半，列表吸附到完全展开或完全收起。没有大标题的页：顶槽下面直接是列表。
3. **进页时大标题的位置可以不同，滚动物理相同。** 主工作区默认展开（列表停在 item 0 顶部）；次级页默认收起（列表停在大标题刚好滚出顶槽）。

横屏分栏额外一条：

4. **右侧默认没有顶栏。** 横屏详情不是一页，应用配置、模板编辑、空状态都直接从内容开始。唯一例外是模板应用选择页：它有工具顶槽（标题 + 搜索/筛选），高度等于左侧列表顶槽（同一 chrome token，不含 status bar、不含大标题）。起始位置避开 status bar；竖向分栏线和滚动后的内容可以画进 status bar，不要用容器 padding 把它们裁掉。

## 四类表面

| 表面 | 第一眼 | 顶槽里有什么 | 大标题 |
|---|---|---|---|
| 主工作区 Home / Settings / Tools | 大标题已展开 | 无返回；短标题在大标题收走后出现；可有操作 | 有，上滚收走 |
| 主工作区 App / 模板 | 无大标题 | 搜索或工具，高度 = 共用顶槽 | 无 |
| 次级页（关于、主题、字体库、日志、捐赠…） | 大标题已收进顶槽 | 圆形返回 + 短标题 + 操作；返回键在安全区后再右移 TitleInset；该 inset 不再叠到标题上；正文左右吃同一套水平安全区 | 有，下拉才出现 |
| 横屏分栏右侧详情 | 不是一页 | 默认无顶栏；仅模板应用选择页有工具顶槽，**高度与左侧顶槽相同** | 无 |

Wear、弹层、编辑器、配置对话框不在本合同内。

## 宿主与页

- **壳（WorkspaceShell）** 只拥有底栏 / rail / drawer 和它们占用的 inset。把这份 padding 交给当前页。壳不挂 nested scroll，不拥有标题。
- **页** 只提供列表项。顶槽、大标题（item 0）、LazyColumn、松手吸附都由 PageScaffold 拥有。页面不再各自包一层 LazyColumn，也不再手写 `pageExpandedTitle()`。
- 列表边距由脚手架给出（宿主 padding + 顶槽 + 大标题），页面不要再抄一套 `TitleToContentGap + 16.dp`。

## 明确不做

- 不用 `TwoRowsTopAppBar` / `LargeFlexibleTopAppBar` 靠改测量高度表达折叠。
- 不为「更像 Material 大顶栏」把标题形态和列表布局绑回同一帧。
- 不把分栏详情当成次级页（不下拉出大标题）。
- 不把 App/模板做成带大标题的 Settings 变体。

## 实现时的验收

- 主工作区与次级页滚动时，顶槽像素高度稳定。
- Settings 一类带卡片的列表，滚动不再因顶栏高度变化而整页 relayout。
- 次级页进页即为收起态，下拉可出大标题；主页进页即为展开态。
- 横屏 App / 模板编辑：右侧无顶栏。模板应用选择页的顶槽与左侧搜索槽对齐、同高。
- 滚动位置与折叠偏移共用一种页级恢复，不再经 `MainUiState` 另存一份列表位置（实现波次里再迁 App 列表）。
