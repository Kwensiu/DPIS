# Issue Tracker

DPIS tracks work in GitHub Issues for `Kwensiu/DPIS`.

## Tooling

- Use the `gh` CLI for issue and pull request operations when available.
- Prefer linking code changes to the relevant GitHub issue when one exists.
- Do not create local issue files unless the user explicitly asks for a local-only planning artifact.

## Agent Expectations

Skills such as `to-issues`, `triage`, and `to-prd` should treat GitHub Issues as the source of truth for tracked work.
