# Triage Labels

Use the default Matt Pocock skill label roles for DPIS unless the repository label vocabulary is intentionally changed.

| Role | Label |
| --- | --- |
| Needs maintainer evaluation | `needs-triage` |
| Waiting on reporter or missing information | `needs-info` |
| Ready for an AFK agent | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

If GitHub labels differ from this table, update this file before running triage automation.
